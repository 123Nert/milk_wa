# 勇者奶蛙传（本地副本）

这是从指定 H5 版本保存的静态游戏文件，包含脚本、样式、图片、音频和结局视频。

在 PowerShell 中运行 `./run-local.ps1`，然后打开 `http://127.0.0.1:4173/`。游戏使用浏览器本地存储保存进度，请保持同一浏览器和地址。直接双击 `index.html` 不适用，因为游戏使用 JavaScript 模块。

当前副本对应线上路径 `BUsvkkbBiAq2pF2Ttx4j/1.0.2/6/`。死亡后可直接点击“重闯本关”，从当前章节入口重新开始，并保留进入章节时的强化；无需观看广告。原脚本备份为 `main-BsKo9vWW.original.js`。
